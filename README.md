# 🧮 MineMath Mod

---

MineMath is a Minecraft mod that introduces an in-game **GUI calculator**, designed to allow players to perform mathematical operations without leaving the game. The mod is compatible with both **Fabric** and **Forge**, ensuring broad accessibility across different modding environments.

This tool is designed to provide a seamless and efficient experience, integrating essential mathematical functionalities directly into the game.

---

## ✨ Features

- **📊 In-Game Calculator**: A fully functional mathematical tool accessible via an intuitive interface.
- **⌨️ Customizable Keybindings**: The default key to open the MineMath interface is **"N"**, but this can be modified in the settings.
- **🔄 Fabric & Forge Compatibility**: Compatible with both modding platforms to maximize usability.
- **🎨 User-Friendly Interface**: A clean and efficient design for easy interaction.

## 🚀 Installation

### 📦 Requirements
- **Minecraft**
- **Fabric API** or **Forge Mod Loader**, depending on the chosen modding platform

### 📥 Download & Setup
1. Download the latest release from [Modrinth](https://modrinth.com/mod/minemath) or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/minemath).
2. Move the **`.jar`** file into the `mods/` folder of the Minecraft installation.
3. Launch Minecraft with either **Fabric** or **Forge**, and the mod will be available for use.
